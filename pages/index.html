Recollection Wisconsin Redesign Process

This project hub is designed to tell the story of the Recollection Wisconsin redesign from start to finish. It begins with research and user-flow exploration, moves through homepage and user-type wireframes, and leads into the final editorial redesign and completed project.

Rather than showing only finished deliverables, this page documents the evolution of the design process and how stakeholder feedback shaped each stage of the work.

Step 1 Research artifacts established the strategic foundation.
Step 2 User flows explored site structure and pathways.
Step 3 Homepage wireframes developed the landing-page direction.
Step 4 User-type pathways extended the work into audience-specific journeys.
Step 5 Final Version 1 shows the approved visual direction.
Step 6 V2 Editorial Redesign layered the design system and accessibility.
Step 7 Final complete version ready for client handoff.
About

About This Project

This repository documents the LIS 640 Industry-Led Capstone redesign process completed in collaboration with WiLS for Recollection Wisconsin. It is intended to show both the project outcomes and the design process behind them, from research and user flows to wireframes and the final editorial redesign.

Step 1

Research Artifacts

These materials helped shape the redesign direction and connect user needs, stakeholder priorities, and design decisions.

User Personas & Journey Map (PDF)
Primary personas and journey insights used to ground the redesign in user needs and motivations.
Strategic Design Alignment Matrix (PDF)
Best-in-class UX patterns mapped to redesign opportunities and stakeholder goals.

User Flows

These flow explorations helped define the site structure, decision points, and user pathways before moving into wireframing.

Tree User Flow
A tree-style flow for exploring paths, branching choices, and site logic.
Interactive User Flow
A click-through prototype for dynamic exploration of information architecture and movement through the site.
User Flow for Everyone
A broader audience version designed for easier stakeholder review and discussion.
Step 3

Homepage Wireframes

These homepage wireframes show how the landing-page concept evolved from early low-fidelity exploration into a more refined structure shaped by feedback.

Low-Fidelity Homepage Wireframe (V1)
An earlier homepage exploration using a shorter-scroll structure.
Intent-Driven Homepage Wireframe (V1)
An alternate early direction using a longer-scroll, intent-driven approach.
Final Low-Fidelity Homepage Wireframe (V2)
The refined low-fidelity homepage direction selected as the strongest structural foundation.

Lo-Fi Wireframes by User Type

These pathway wireframes build on the homepage work by extending the design into more audience-specific journeys.

Contributor Pathway (Lo-Fi)
Built-out contributor pathway in low fidelity. Click through the contributor screens to follow that user journey.
Educator Path 1

Educator Path 2

Step 5

Final Design Direction

Unlike the low-fidelity work above, this version begins to show the look, feel, and overall experience of the proposed redesign more fully. Reviewed and approved by WiLS stakeholders.

Final Version 1
The approved review version following stakeholder discussion. All user pathways are clickable end-to-end.
Step 6

V2 Editorial Redesign

Building on the approved V1, the editorial redesign introduces a four-color audience wayfinding system, sharp editorial typography, hover-lift interaction patterns, and WCAG 2.1 Level AA accessibility compliance.

V2 Editorial Redesign
The editorial design system applied to all 20 pages. Dark header and footer, audience color pathways, responsive from 320px to 4K.
Editorial Style Guide
In-site design system documentation covering the color palette, typography, components, interaction rules, and accessibility features.
V1 for Comparison
Compare with V1 side-by-side to see how the editorial system transformed the same content and interactions.
Step 7 — Final Deliverable

Completed Project

The final, complete version of the Recollection Wisconsin redesign. This is the capstone deliverable ready for client handoff to WiLS.

Final Complete Version
The completed Recollection Wisconsin redesign with all stakeholder feedback applied, full accessibility, and responsive design. Ready for handoff.
