WiLS / Recollection Wisconsin – UX Process, Prototypes & Design Evolution

This project hub is designed to tell the story of the Recollection Wisconsin redesign process from start to finish. It begins with research and early user-flow thinking, moves through homepage and pathway wireframes, and leads into the current final design direction. Rather than showing only final deliverables, this page documents how the work evolved.

Step 2

User Flows

These flow explorations helped define site pathways, choices, and interaction patterns before moving into wireframing.

Tree User Flow
A tree-style flow for exploring key paths, branching decisions, and overall site logic.
Interactive User Flow
A click-through version for more dynamic exploration of structure and movement through the site.
User Flow for Everyone
A broader audience version intended to make the flow easier for stakeholders to review and understand.
Step 3

Homepage Wireframes

These homepage wireframes show how the landing-page direction evolved from early low-fidelity exploration into a more refined structure shaped by feedback.

Low-Fidelity Homepage Wireframe (V1)
An earlier homepage exploration using a shorter-scroll structure.
Intent-Driven Homepage Wireframe (V1)
An alternate early homepage direction with a longer-scroll, intent-driven approach.
Final Low-Fidelity Homepage Wireframe (V2)
The refined low-fidelity homepage direction selected as the strongest foundation for next-step development.
Step 4

Lo-Fi Wireframes by User Type

These pathway wireframes build on the homepage concepts by moving into more audience-specific journeys. This section shows how the project progressed from broad structure into user-type exploration.

Contributor Pathway (Lo-Fi)
Built-out contributor pathway in low fidelity. Click through the contributor screens to follow that user journey.
Educator Path 1
First low-fidelity educator pathway exploration focused on how educators might enter, navigate, and locate relevant teaching-oriented resources.
Educator Path 2
Second low-fidelity educator pathway exploration showing an alternate direction for comparison, refinement, and stakeholder review.
